# sql-lint Specification

## Purpose
SQL 的纯静态规则审核：不连库、不启容器、不联网，对文件/目录/变更集
目录产出逐条命中（规则、级别、位置、建议）；无法解析的语句逐条记录为工具命中并指认文件行，不中断整轮。

## Requirements

### Requirement: 纯静态规则判定

审核 SHALL 基于 SQL 解析对输入做纯静态判定，SHALL NOT 连接数据库、启动容器或
发起网络请求。该纯静态约束的作用域是审核判定与 lint 报告（report_kind=lint）
本体——命中、汇总与退出码全部出自静态判定；`modou lint` 可选附带的 AI 残留
评审（ai_opinions 观点区）不属于审核：不产生命中、不影响退出码，其网络行为由
ai-analyst 能力规格约束（未配置零网络；已配置仅 BYOK 出站，调用失败降级、
不阻塞审核）。无法解析的语句 SHALL 逐条记录为工具命中（PARSE.001：指认文件与位置、
计入命中汇总与退出码），SHALL NOT 静默跳过；其余语句 SHALL 照常审核，SHALL NOT 因
局部解析缺口中止整轮。该工具命中 SHALL 可经规则跳过机制显式关闭。首批规则库 SHALL 不少于 20 条，每条 SHALL
具备唯一标识、级别、说明、改写建议，并以正例（应命中）与反例（不应命中）测试
覆盖。

#### Scenario: 断网环境照常审核

- **GIVEN** 无任何数据库、容器与网络的环境
- **WHEN** 用户对 SQL 文件执行审核
- **THEN** 审核正常完成并产出结论

#### Scenario: 无法解析的语句逐条记录

- **GIVEN** 输入文件含无法解析的语句（如版本条件注释、存储过程体）
- **WHEN** 用户执行审核
- **THEN** 该语句记录为工具命中 PARSE.001 并指认文件与大致位置，其余语句照常审核，
  退出码为 1；显式跳过 PARSE.001 且无其他命中时退出码为 0

#### Scenario: 规则正反例逐条可测

- **GIVEN** 首批规则清单
- **WHEN** 逐条以其正例与反例执行审核
- **THEN** 每条规则在正例命中、在反例不命中

### Requirement: 规则可配置可跳过

规则启用状态与数值阈值 SHALL 可经配置文件调整，未提供配置时 SHALL 以文档化的
默认值运行。命令行显式跳过 SHALL 存在且优先级高于配置文件。

#### Scenario: 禁用规则后不再命中

- **GIVEN** 某规则在配置文件中被禁用
- **WHEN** 对该规则的正例执行审核
- **THEN** 报告不含该规则命中

#### Scenario: 命令行跳过优先

- **GIVEN** 某规则在配置文件中启用，但命令行显式跳过该规则
- **WHEN** 对该规则的正例执行审核
- **THEN** 报告不含该规则命中

#### Scenario: 阈值调整改变判定

- **GIVEN** 单表索引数上限阈值由默认值调整为更大值
- **WHEN** 对超出默认阈值但未超出新阈值的建表语句执行审核
- **THEN** 该规则不再命中

### Requirement: 命中输出与退出码

每次命中 SHALL 输出规则标识、级别、文件与位置、消息与建议，并 SHALL 同时提供
人读文本与机读 JSON 双出口。退出码 SHALL 确定性映射：0=无命中，1=存在命中
（已启用规则的命中或无法解析语句的工具命中），2=环境或输入错误。变更集目录作为输入时 SHALL 仅审核 SQL 文件内容，
SHALL NOT 因清单不一致拒绝（清单校验属打包职责）。

#### Scenario: 存在命中

- **GIVEN** 输入包含至少一条已启用规则的命中
- **WHEN** 用户执行审核
- **THEN** 报告逐条列出命中（含标识、级别、位置、建议），退出码为 1

#### Scenario: 无命中

- **GIVEN** 输入不含任何已启用规则命中
- **WHEN** 用户执行审核
- **THEN** 退出码为 0

#### Scenario: 变更集目录输入

- **GIVEN** 一个变更集目录（含版本命名 SQL 文件与清单文件，且清单与目录不一致）
- **WHEN** 用户对该目录执行审核
- **THEN** SQL 文件内容照常审核，不因清单不一致拒绝
