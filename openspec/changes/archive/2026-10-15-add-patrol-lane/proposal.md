# 提案：v0.4 第二刀——洞察车道（patrol）

## Why

漂移洞察是四车道里唯一「时间维度」的能力：变更验收回答「这次变更落对没有」，
巡检回答「两次采集之间线上被改了什么、哪些索引在白吃写放大、慢日志里谁在重复
作案」。全部结论由确定性代码出具（ADR-0003，本车道无 AI）；零平台化——无常驻
进程、无自调度，定时由外部调度器承载（cron / systemd timer），工具只做一次性
命令（ADR-0002）。

## What Changes

- `modou patrol drift`：两份结构快照（或基线快照 + 现场实采第二份）→ 两方结构
  漂移报告（新增 / 缺失 / 定义变更，复用 v0.1 维度 diff 核心）；退出码
  0=无漂移、1=存在漂移、2=环境或输入错误（结论性输出使用 1）。
- `modou patrol unused-indexes`：
  - 连库模式：表 I/O 计数与服务器运行时长交叉校验 → 分层判定（确认未用 /
    疑似低用 / 数据不足），排除主键与唯一性索引并说明语义、排除或标注外键依赖；
  - 离线模式：纯快照元数据的冗余索引判定（三情形，附可执行 DROP 建议）。
  建议性输出，退出码 0/2，不使用 1。
- `modou patrol slowlog`：本地解析慢日志文件（零连接）→ 查询指纹聚合（字面量
  归一、IN/VALUES 列表折叠，行业事实口径）→ 按累计耗时排序 top 榜 + 样本语句，
  文本 + JSON 双出口；建议性输出，退出码 0/2。
- 调度示例文档（cron / systemd timer）；MCP 工具同步扩列。

## 受影响决策

- ADR-0002：零平台化——无常驻、无自调度、无告警推送，外部调度器承载定时。
- ADR-0003：全部结论出自确定性代码与库元数据。
- ADR-0008：多库默认，报告按库分组。

## 顺序与依赖

- 前置：v0.1（快照与维度 diff 复用）、v0.3（MCP parity 扩列）。
- 与 lint / ui 无相互依赖，按 v0.4 排序第二个落地（ui 需要消费本车道报告形态）。

## 不做清单（Non-goals）

- 不做常驻守护进程、自调度器、告警推送（零平台化红线）。
- 不做语句摘要表（digest 表）直读采集——其指纹口径与文件口径不可互认（不折叠
  IN 列表、1024 字节截断、容量上限），列为后续独立口径再议。
- 不做自动 DROP/清理（只出建议与语句，执行永远归人）。
- 不做线上长事务/MDL 锁巡检（变更期锁预警 pack 已有；线上锁巡检后续再议）。
- 不做 PG（ADR-0005）。
