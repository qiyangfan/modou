# 设计：AI 分析师层（v0.5）

> 方法论参照：alibaba/open-code-review 调研（docs/research-2026-10.md 增补节，
> 2026-10-16）；决策论证见 ADR-0009。本文只写落地方案。

## 1. 交互形态选型（tools / skills / MCP / 子代理 vs 纯文本）

| 路线 | 收益 | 代价 | 裁决 |
|---|---|---|---|
| 内置 tool-use agent（AI 自主调 EXPLAIN 等） | 质量上限最高 | agent harness 全套复杂度进内核；BYOK 端点 tool-call 能力参差；fail-safe 降级复杂 | 演进位，不开工（触发条件见 ADR-0009） |
| 宿主 delegation（MCP 证据工具 + skills） | 零密钥兑现 AI 赋能；模型能力随宿主升级；数据不出本地 | 依赖宿主 Agent 能力 | **主通道，P0** |
| BYOK 纯文本（证据预取打包 + 结构化输出） | 最可移植（stdlib HTTP）、最可测（transport 注入）、可并发 | 单轮上下文有限，靠切片/分包兜 | **内置通道，P1/P2** |
| 内置子代理编排 | 隔离上下文并发 | 编排框架进内核 | 否决：分包 + 并发单轮等价实现该收益 |

关键判据：OCR 实证"确定性供证据 > agent 自主探索"（省 token、稳定、可审计）；
modou 的实证关又兜住内置 AI 的质量风险——候选反正要过影子库，观点不碰退出码。
因此内置通道的"多轮"由**确定性流水线驱动**（预取 → 打包 → 单轮 → 校验），
不由模型驱动。

## 2. 结论分级与退出码

| 级别 | 判定来源 | 退出码关联 | 展示位置 |
|---|---|---|---|
| 实证已验证 | 确定性代码 + 影子库实测 | 是（现状不变） | 报告正文 |
| AI 观点 | BYOK 模型输出 | 否（契约测试守护） | 报告"AI 观点"区，附来源与"未实证"标注 |

- 未配置 BYOK：无 AI 观点区，四车道行为与 v0.4 完全一致（回归测试证明）；
- 已配置但调用失败：AI 观点区标注降级原因，报告照常产出（fail-safe 沿用
  advisor 现行语义）。

## 3. 委托面（通道 A）

- MCP 证据原语工具清单（每个工具与 CLI 对应物的 JSON 出口对齐，parity 清单扩列）：
  快照摘要（snapshot）、回放验收（verify）、三方 diff（verify/diff）、
  EXPLAIN（optimize）、lint 命中（lint）；
- skills 资产：数据库变更评审工作流（打包 → 预警 → 影子库验收 → 报告解读 →
  优化建议实证），随包分发纯文本模板，零代码零依赖；
- 1:1 契约延伸口径：证据工具是既有子命令机读出口的暴露，不新增 MCP 独有逻辑
  （ADR-0002 表面层零业务逻辑不变）。

## 4. 内置通道（通道 B）上下文工程

- **schema 切片器**：按语句触达的库/表裁剪上下文，只发相关子集（现有
  build_schema_summary 全量摘要升级为切片，token 预算上限可配置）；
- **变更分包器**：变更集按库/语句组分包，每组独立评审可并发（OCR 分包思想，
  map-reduce 式并发单轮）；
- **规则注入器**：lint 命中清单作为规则上下文注入残留评审（模板引擎注入，
  非自然语言转述——OCR 的规则匹配经验）；
- **提示词模板**：每车道场景化模板，版本化入库，评测集回归守护；
- **BYOK 客户端**：自 optimize/advisor.py 演进收拢进 `ai/`（stdlib HTTP、
  transport 注入可测、fail-safe 降级语义不变），optimize 车道改为调用方。

## 5. 各车道 AI 工作流（P1）

- **lint 残留评审**：规则引擎先跑 → 命中项作为上下文 → 残留语句分包送 AI →
  语义风险观点（语句间顺序、依赖冲突、意图错位等规则表达不了的问题）；
- **verify 归因**：三方 diff 事实 → AI 解释漏执行/错执行/漂移的成因与修复建议；
- **patrol 叙事**：漂移 + 未用索引 + 慢日志指纹 → AI 跨信号综合洞察；
- **optimize（P2）**：EXPLAIN 事实预取打包 → AI 候选 → 影子库实证（实证关不变，
  候选生成从 one-shot 升级为带事实的受控多轮）。

## 6. 评测（P2）

- 抽样评测集：lint 残留评审正例（真问题）与反例（规则已覆盖/无害语句），
  首版精度数字入库；
- 回归纪律：提示词、模板、切片逻辑任何变更必跑评测，劣化即失败（宪法工程口径）；
- optimize 延续既有度量：AI 候选过实证关比例。
