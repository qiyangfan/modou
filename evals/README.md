# 评测集（v0.5 design §6）

AI 分析师层的回归门禁数据集。宪法工程口径：**提示词、模板、切片逻辑任何变更必跑评测，劣化即失败。**

## lint_residual（审核车道残留语义评审）

- `cases.json`：正例（规则盲区内的真风险，AI 应出观点）+ 反例（无害语句，AI 应沉默）。
  语句刻意规避 26 条静态规则——进得了残留面才有评审资格。
- `last-run.json`：最近一次 BYOK 实测的精度数字（由门禁自动落盘，入库留痕）。

## 运行方式

```bash
# 确定性半区（零密钥，恒跑）：数据集聚合性 + 上下文工程回归
uv run pytest tests/evals -q

# BYOK 半区（三元组齐备才跑；未配置 skip 不假绿）
MOUDO_AI_BASE_URL=... MOUDO_AI_API_KEY=... MOUDO_AI_MODEL=... uv run pytest tests/evals -q
```

## 门禁语义

- 确定性半区失败 = 上下文工程（残留提取/分包/注入/提示词契约）被改坏，必须修复；
- BYOK 半区失败 = 精度劣化到地板以下（首版数字实测后校准 `ACCURACY_FLOOR`），
  或端点不可达（评审整体降级、正例全空）——两者都阻塞提示词类变更合入。
- 首版精度数字（待确认）：需 owner 配置 BYOK 端点实测一次；数字回写本文件并校准地板。
