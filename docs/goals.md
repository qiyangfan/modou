> 北极星与可测判据。验收一律以可复现命令输出为准，不靠主观感觉；
> 治理红线见 [openspec/project.md](../openspec/project.md)（宪法），技术路线见
> [architecture.md](architecture.md)。

## 北极星

让"数据库变更是否落对、SQL 优化是否有效"从经验判断变成**机器证据**，
任何团队**零流程改造**即可获得。

## 里程碑与验收判据

### v0.1 —— 变更车道（pack + verify，仅 MySQL）

- 真实迭代形态的变更集目录 → `pack` 产出合并脚本与破坏性预警；
- 人工构造的漏执行 / 错执行 / 历史漂移三类用例，`verify` 全部抓到并正确归类，
  退出码符合 spec 定义（0/1/2）；
- 快照 round-trip 零假差异（字符集、触发器、存储过程用例全过）；
- 多库变更集聚合报告正确；
- 端到端（采集→回放→验收）单迭代耗时 ≤ 10 分钟。

### v0.2 —— 优化车道（optimize）

- 慢 SQL 输入 → 规则命中 + AI 建议 → 影子库实测；
- 报告中每条建议带"实测提升 X%"或明确标"未验证"，无第三种状态；
- 建议副作用检查：冗余索引（被现有索引前缀覆盖）、单表索引数上限、写放大提示。

### v0.3 —— MCP 表面 + CI 集成

- MCP 工具与 CLI 子命令 1:1，无 MCP 独有逻辑；
- agent 一句话完成"校验这个变更集并优化其中的慢 SQL"的演示链路；
- GitHub Actions 示例：PR 上自动跑 pack 预警。

### v0.4 —— 审核车道 + 洞察车道 + 报告 UI

- lint 规则库 ≥ 20 条（SOAR 高频反模式子集起步），规则可配置、可跳过；
- patrol：定时漂移 diff、未用索引检测、慢日志指纹聚合；
- `modou ui` 本地渲染 diff/EXPLAIN 报告。

### v1.0 —— 对外发布

- PyPI 发布，`uv tool install modou` 一条命令可用；
- 中英双语 README，真实场景案例两个（含本团队一次完整迭代）；
- 文档齐备：快速上手 / 变更集规范 / 规则清单 / MCP 接入。

## 度量口径

| 指标 | 口径 |
|---|---|
| 验收有效性 | 漏执行构造用例检出率 = 100%（漏检一次即 P0 缺陷） |
| 误报率 | 快照保真导致的假差异 = 0（出现即回放器缺陷） |
| 建议可信度 | 报告中"实测提升"标注的建议，抽样复核达标率 100% |
| 安装门槛 | 核心依赖 `uv sync` 完成时间 ≤ 30s（重依赖在 extras） |
