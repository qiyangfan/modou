# ADR-0004：回放推导期望态，不用解析器拼终态

- 状态：接受
- 日期：2026-10-14
- 依据：DDL 解析边角风险清单 + Skeema execute-and-introspect 同思路佐证

## 决策

变更集的期望态一律由**真实数据库回放**推导：执行前快照灌入同版本影子库 MySQL，
在其上重放变更集，得到的终态即期望态。DDL 解析（sqlglot）只服务于两个非结论场景：
pack 时的破坏性/锁风险预警、lint 车道的规则扫描。

## 理由

- DDL 解析器对存储过程、注释、字符集/collation 继承、生成列等边角的累积误差难以消除，
  任何"解析 N 条 DDL 拼出终态"的实现都会在这些地方产生假差异；
- 回放让数据库自己算，误差源收敛为"影子库与目标库版本/配置差异"，可用同大版本约束
  封死；Skeema 的 execute-and-introspect 多年生产验证同思路。

## 后果

- 影子库生命周期管理（拉起/灌入/销毁）成为内核一等公民，测试依赖容器 fixture；
- 快照 round-trip 保真成为第一风险项（HANDOFF 已列），原型阶段最先验证；
- 对无法回放的语句类型（如涉及在线数据的 DML 订正）采用行数 + checksum 抽查口径，
  不硬套回放。
