# ADR-0007：变更集规范向 Flyway 靠拢

- 状态：接受
- 日期：2026-10-14
- 依据：降低用户迁移成本与心智负担

## 决策

变更集文件命名 `V<序号>__<描述>.sql`（两位以上零填充序号），每目录附 manifest 清单；
一个迭代一个目录。回放顺序 = 序号顺序。

## 理由

- Flyway 的 V 命名是行业最普及的迁移心智，用户零学习成本；
- 将来用户的流程放开（开发直连执行迁移）时，目录可被 Flyway 类工具直接接管，
  墨斗无锁定；
- manifest 承担"打包零遗漏"的校验锚点（目录与清单一一对应），命名规范负责排序，
  职责分离。

## 后果

- 发现器对非 V 命名文件默认拒绝并提示重命名（可显式关闭以接纳存量目录）；
- 序号重复、跳号属警告级（不阻塞），manifest 不一致属错误级（阻塞）。
