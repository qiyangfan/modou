# ADR-0008：默认多实例多库

- 状态：接受
- 日期：2026-10-14
- 依据：owner 全局宪法——所有项目默认多实例，单实例假设必须显式防护

## 决策

墨斗所有命令域按**多库清单**工作：变更集可涉及 N 个库，verify 逐库执行并聚合报告，
退出码取最严重档。任何阶段的代码不得隐式假设仅存在单个库或单个数据库实例；
"单库"必须是用户显式给出的配置，不是默认路径。

## 理由

- 目标场景（一次迭代几十条 SQL）天然跨库：业务库、配置库、多租户分库皆常见；
- 单库假设一旦渗入内核数据结构（如全局连接单例），事后抽掉的成本远高于一开始做对；
- 快照、回放、报告的容器结构从第一天就按 `库 → 对象 → 维度` 组织。

## 后果

- 影子库编排需支持多库灌入（一容器多库，而非一库一容器）；
- 报告格式按库分组是稳定契约，v0.1 起冻结，避免下游（CI 插件、MCP 消费方）跟着改。
